Frequently asked questions

Clear answers before you order.

Are the tools ready to use?

Yes. The listed products are intended as editable HR workbooks/templates. Exact file contents can be confirmed before fulfilment.

Is online payment live?

The current GitHub demo uses an enquiry/order flow. Razorpay should only be enabled after a secure server-side order creation and payment verification flow is configured.

Can you customise an Excel dashboard?

Yes. Use the service enquiry form and describe the columns, calculations, reports and HRMS/data source you need.

Will my card or UPI details be stored here?

HRToolKit India should not store payment credentials. When a production gateway is connected, payment processing should occur through the gateway and server-side verification.

Privacy by design

Only information necessary for an order or enquiry should be collected. Marketing consent should be optional and separate. Payment card credentials are not stored by this site.

This implementation is designed to support applicable requirements under India's Digital Personal Data Protection framework; it is not a legal certification. Obtain legal review before making a formal compliance claim.
