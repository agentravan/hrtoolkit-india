# HRToolKit India — Production Automation Setup\n\n## Implemented flow\n1. Customer selects a ready-made kit or creates a custom dashboard.\n2. Customer enters name, email and mobile.\n3. Server creates a Razorpay Order using the server-side secret.\n4. Razorpay Checkout handles payment.\n5. The Razorpay payment.captured webhook is verified with HMAC.\n6. The server reads trusted Razorpay order notes.\n7. A ZIP is generated for the exact modules and compatibility choices.\n8. Customer receives the ZIP by email.\n9. Admin receives a payment notification containing customer, product, amount, Razorpay IDs and compatibility.\n\n## Vercel environment variables\nSet these in Project → Settings → Environment Variables:\n- RAZORPAY_KEY_ID\n- RAZORPAY_KEY_SECRET\n- RAZORPAY_WEBHOOK_SECRET\n- ZOHO_SMTP_HOST=smtp.zoho.in\n- ZOHO_SMTP_PORT=587\n- ZOHO_SMTP_SECURE=false\n- ZOHO_SMTP_USER=teamwork.hrsolution@zohomail.in\n- ZOHO_SMTP_PASS=<your Zoho SMTP/app password>\n- MAIL_FROM=teamwork.hrsolution@zohomail.in\n- ADMIN_EMAIL=teamwork.hrsolution@zohomail.in\n\n## Razorpay webhook\nCreate this webhook in Razorpay Dashboard:\nhttps://YOUR-VERCEL-DOMAIN/api/razorpay/webhook\nUse the same random value as RAZORPAY_WEBHOOK_SECRET and enable payment.captured.\n\n## Power BI\nThe web server does not fabricate a binary PBIX. The kit contains supported PBIDS/data/DAX/setup inputs. A real PBIX/PBIT is authored or exported through Power BI Desktop/Service.\n\n## Power Automate\nThe kit contains a starter flow definition and connector/setup guide. A production solution/package should be exported from the customer's Microsoft environment because connector references and environment values belong to that tenant.\n\n## Security\nNever commit Razorpay secrets, Zoho passwords, customer PII, or payment credentials. Use Vercel environment variables.
